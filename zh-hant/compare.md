選擇照片清理 App 前，請確認它如何挑選照片、確認刪除，以及保護隱私。以下介紹 Alike 的做法。

| 要確認什麼？ | Alike |
|---|---|
| 相似照片還是副本？ | 依時間、地點與相似度分組，提供 3 種靈敏度。 |
| 如何挑選最佳照片？ | 依清晰度、曝光、人臉與雜訊評估，在裝置上從你的選擇學習。 |
| 刪除後會怎樣？ | Alike 與 iOS 均要求確認。照片通常在「最近刪除」保留 30 天。 |
| 在哪裡分析？ | 使用 iPhone 上的 Apple Vision。掃描與清理可在飛航模式下運作。 |
| App 隱私權？ | 「未收集資料」。沒有使用分析或追蹤。 |
| 帳戶或廣告？ | 不需帳戶或登入，沒有廣告。 |
| 有哪些方案？ | 每月免費掃描 3 次。Pro 提供月繳與年繳，沒有週繳。 |
| 有小工具嗎？ | 在主畫面與鎖定畫面顯示可釋放空間。 |

## Alike 適合誰？

Alike 適合從相似照片中挑選要保留的畫面。它不會壓縮影片或轉換 Live Photos。免費版包含最佳照片、照片增強與小工具。Pro 加入批次清理、截圖清理、模糊照片清理與進階篩選。

免費版每月提供 3 次掃描，每次清理一張照片。Alike Pro 提供以當地貨幣計價的月繳與年繳方案。符合資格的新訂閱者可享年繳方案 7 天免費試用。
